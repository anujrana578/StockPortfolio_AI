# FinSight — Portfolio Management & AI Predictor

FinSight is a full-stack portfolio management application featuring a real AI/ML stock price prediction engine built with XGBoost.

## Project Architecture

- **Frontend**: React, TypeScript, Vite, Tailwind CSS, Recharts
- **Backend**: Python, Flask, SQLite, XGBoost
- **Authentication**: JWT-based Session Management, Google OAuth

## Setup & Running

### 1. Backend Setup

1. Install Python dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Historical data and a trained model are included for local development. To
   retrain the model with new CSV data, run `python ml/train_model.py`.

### 2. Frontend Setup

1. Install Node modules:
   ```bash
   npm install
   ```
2. Set up environment variables (if required for Google OAuth):
   Create a `.env` file and set `VITE_GOOGLE_CLIENT_ID`.
3. Start the Flask API and Vite frontend together:
   ```bash
   npm run dev
   ```
   The API runs on `http://127.0.0.1:5000` and the frontend on
   `http://localhost:5173` (or the port Vite outputs). The frontend proxies
   `/api` requests to Flask. Both servers must stay running for API features.
   To run one server separately, use `npm run dev:api` or
   `npm run dev:frontend`.

## AI Predictor Details
The prediction engine utilizes multi-dimensional feature engineering:
- **Technical Indicators**: RSI (14), MACD, Moving Averages (7, 20, 50, EMA-12, EMA-26), Volatility, Momentum, Bollinger Bands.
- **Model**: XGBoost Regressor trained on the historical closing prices with chronological cross-validation to prevent look-ahead bias.
- **Forecasting**: Predicts 30-day target price, generating confidence intervals dynamically and predicting sequential daily boundaries using an additive noise dispersion method.
